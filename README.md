## For Linux Users

### Installation

1. Navigate to the `linux` folder where the files `install.sh` and `script_linux.py` are located.
2. Before running the installation script, you need to make it executable. Use the following command in the terminal:

    ```bash
    chmod +x install.sh
    ```

3. After making the `install.sh` file executable, run it with the following command:

    ```bash
    ./install.sh
    ```

    This script will set up the necessary environment for running `script_linux.py`.

### Running the Script

- After installation, run the Python script using the following command:

    ```bash
    python3 script_linux.py
    ```

## For Windows Users

### Installation and Execution

1. Navigate to the `windows` folder, where the `install.bat` and `script_windows.py` files are located.
2. Execute the `install.bat` file by double-clicking it. This script prepares the environment for running `script_windows.py`.
3. To run the `script_windows.py`, open a command prompt in the same folder and type:

    ```cmd
    python script_windows.py
    ```
